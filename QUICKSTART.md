# RecursiveLearn - Quick Start Guide

## 🚀 Get Started in 3 Minutes

### Installation

#### Windows
```batch
# Double-click these files:
1. install.bat   (installs dependencies)
2. run.bat       (launches app)
```

#### Linux/Mac
```bash
pip install -r requirements.txt
./run.sh
```

## 📚 Your First 5 Minutes

### 1. Complete Your First Lesson (2 min)

1. Click **📘 Lessons** in sidebar
2. Select "Lesson 1: Sequences and Recurrence Relations"
3. Read "What is a Sequence?"
4. Click **Next** through sections
5. Click **✓ Mark Lesson Complete** at the end
6. **Earn:** +100 points + 🎓 badge

### 2. Solve Your First Problem (2 min)

1. Click **🧮 Solver** in sidebar
2. Click the **"Simple Linear"** example button
3. Click **🔍 Solve**
4. See the solution and sequence!
5. Click **📄 Export PDF** to save

### 3. Visualize a Sequence (1 min)

1. Click **📊 Visualizer** in sidebar
2. Click **"Fibonacci"** example
3. Click **📈 Plot Sequence**
4. See the beautiful graph!

## 🎯 Common Tasks

### Solve a Recurrence Relation

**Input:**
```
Relation: a_n = a_(n-1) + 5
Initial:  0:5
```

**Click:** 🔍 Solve

**Output:**
```
Closed form: a_n = 5 + 5n
Sequence: 5, 10, 15, 20, 25, ...
```

### Plot a Sequence

**Input:**
```
Relation: a_n = 2*a_(n-1)
Initial:  0:1
Terms:    15
```

**Click:** 📈 Plot Sequence

### Practice an Exercise

1. **🧠 Practice** → Select exercise
2. Enter your answer
3. **✓ Check Answer**
4. Get instant feedback!

## 🆘 Quick Troubleshooting

**Problem:** Solver says "Could not parse"  
**Solution:** Check syntax - use `a_(n-1)` not `a_n-1`

**Problem:** Graph doesn't show  
**Solution:** Verify initial conditions format: `0:5, 1:10`

**Problem:** App won't start  
**Solution:** Run `pip install -r requirements.txt`
